# 몰까 사이트 전체 점검 보고서

점검일: 2026년 10월 2일
대상: 현재 저장소의 한국어·영어·일본어·중국어 페이지와 콘텐츠·공통 스크립트·API 연결·이미지·SEO·반응형 화면
적용 범위: 점검 수정 사항을 저장소 변경으로 기록했습니다. `main` 브랜치 푸시가 Cloudflare Pages 자동 배포를 시작합니다.

## 요약

- **P2 오류 1건 수정:** 월드컵을 끝낸 뒤 다시하기로 새 게임을 시작하면 선택지가 투명해져 빈 화면처럼 보이는 문제를 수정했습니다.
- **번역 정리:** 현재 코드에서 참조하지 않는 번역 키 195개를 한국어·영어·일본어·중국어 파일에서 정리했습니다. 동적으로 만들어 사용하는 검색 태그·콘텐츠 형식·최근/즐겨찾기 탭 키는 유지하고, 이 예외도 검사 스크립트에 반영했습니다.
- **번역 문구 2개 개선:** MBTI 첫 질문의 영어·일본어·중국어 표현이 직역투여서 각 언어에서 자연스럽게 읽히도록 다듬었습니다.
- **밸런스:** 점검한 11개 성향·스토리 콘텐츠에서 결과 도달 불가 또는 3% 미만 결과는 없었습니다. 점수 배분은 바꾸지 않았습니다.
- **P1 및 차단 수준 결함:** 이번 저장소 점검에서는 발견되지 않았습니다.

## 발견 사항과 수정

### P2 — 월드컵 재시작 뒤 선택지 화면이 사라짐

완료 화면을 띄울 때 선택지 영역에 `archetype-stage--leaving` 전환 클래스가 남습니다. 다시하기가 화면을 초기화하고 새 게임을 시작해도 이 클래스가 제거되지 않아 선택지의 계산된 불투명도가 `0`으로 유지됐습니다.

공통 월드컵 렌더러와 초기화 함수에서 이전 진입·퇴장 클래스를 지우도록 고쳤습니다. 일반 주말 취향·야식·한 달 살기 월드컵의 한국어·영어·일본어·중국어 페이지 12곳의 `worldcup.js` 캐시 토큰도 함께 갱신했고, 같은 회귀가 생기면 검사에서 잡히도록 했습니다.

로컬 브라우저에서 16강을 끝까지 진행한 뒤 다시하기와 새 게임 시작을 확인했습니다. 수정 전 재현 화면은 불투명도 `0`, 수정 후 새 선택지는 불투명도 `1`로 표시됐습니다.

### P3 — 참조되지 않는 번역 항목

한국어 기준 1,782개 중 195개 키는 페이지·스크립트·콘텐츠 데이터 어디에서도 사용되지 않는 오래된 항목이었습니다. 같은 키가 4개 언어 파일에 남아 있어 번역 현황을 파악하기 어렵고, 오래된 문구가 갱신 대상으로 오인될 수 있었습니다. 해당 키와 대응 번역을 4개 언어에서 제거하고, 참조되지 않는 키가 다시 쌓이지 않도록 통합 검사에 검사를 추가했습니다.

정리 후 각 언어 파일은 1,782개 키로 맞습니다. 누락·빈 문자열·언어 간 키 차이는 없고, 영어·일본어·중국어 값의 한글 혼입이나 중국어 문장에 남은 영어 문장도 검출되지 않았습니다. 콘텐츠 검색 태그, 월드컵·퀴즈·스토리 형식, 즐겨찾기·최근 탭의 동적 키는 정상 사용 중이라 보존했습니다.

### 번역 문구 — MBTI 첫 질문

다른 언어 화면 표본을 확인하면서 첫 질문의 “에너지를 나눈다” 표현이 영어·일본어·중국어에서 어색하게 직역된 것을 발견해 다듬었습니다. 질문도 각 언어에 맞는 자연스러운 표현으로 수정했습니다.

- 영어 답변: “Meet up with close friends and recharge.”
- 일본어 답변: “親しい人と会って、元気をもらう”
- 중국어 답변: “和亲近的人见面，让自己恢复精力”

수정된 세 언어 화면에서 제목과 질문·선택지를 확인했고, 한국어 문자열이 노출되지 않는 것도 확인했습니다. 전체 문장을 원어민이 모두 교정한 것은 아니며, 이번 번역 평가는 키 누락·언어 혼입 검사와 주요 화면 표본 확인을 포함합니다.

## 점검 결과

### 경로·연동·콘텐츠

기존 통합 검사와 추가한 번역 참조 검사를 실행했습니다. 80개 지역화 페이지, 콘텐츠 목록과 추천, SEO 메타데이터, 월드컵 데이터와 API, 성향 테스트 데이터·이미지, 사이트맵·리디렉션, D1 문서 및 캐시 참조를 포함해 **17,639개 검사가 통과**했습니다.

로컬 브라우저에서 동물상 10문항, MBTI 20문항, 판타지 직업 8개 선택, 판타지 마을 가게 이야기, 16강 월드컵의 완료·다시하기 흐름을 확인했습니다. 각 결과 화면에서 다시 시작했을 때 질문·진행 상태가 초기화되는 것을 확인했습니다.

반응형 화면은 320×720, 390×844, 768×1024, 1440×900 크기에서 월드컵 선택 화면을 확인했습니다. 가로 넘침은 없었습니다.

### 소개·개인정보·운영 연동
