# 취미 찾기 결과 만화

다섯 결과 이미지는 각각 정사각형 2×2 네 컷 카툰입니다. 한 이미지 안에서는 주인공의 모습과 옷차림을 유지하고, 네 장면을 순서대로 보았을 때 취미를 시작해 작은 결과를 얻는 흐름이 대사 없이 이해되어야 합니다. 이미지 안의 글자, 말풍선, 캡션, 로고는 사용하지 않습니다.

휴식 취향 결과 만화와 같은 인물이나 초록·크림 중심의 색감은 되풀이하지 않습니다. 다섯 유형은 서로 다른 인물, 공간, 색 팔레트와 그래픽 표현으로 구분하며 작은 썸네일에서도 행동을 알아볼 수 있게 단순하게 그립니다.

| 파일 | 결과 | 장면 |
| --- | --- | --- |
| `maker.jpg` | 작은 것을 완성하는 메이커 | 남성이 골판지 조각을 접어 책상 정리함을 만듭니다. |
| `grower.jpg` | 천천히 기르는 가드너 | 흰 수염을 기른 남성이 옥상 텃밭에서 허브를 심고 돌본 뒤 수확합니다. |
| `flavor.jpg` | 새 조합을 찾는 맛 연구가 | 남성이 재료를 섞어 간식을 만들고 친구와 나눕니다. |
| `observer.jpg` | 작은 차이를 기록하는 관찰자 | 여성이 망원경으로 밤하늘을 보고 달을 기록합니다. |
| `puzzler.jpg` | 규칙을 설계하는 퍼즐 메이커 | 젊은 사람이 타일 퍼즐을 만든 뒤 친구들과 시험합니다. |

이미지 생성 요청은 단순한 행동 전달을 위한 카툰이며, 대사나 화면 안 텍스트 없이 네 컷으로 이어지는 장면을 지정합니다. 이미지 대체 텍스트와 결과 설명은 `assets/js/hobby-discovery-data.js`와 네 언어 JSON 파일에서 관리합니다.
