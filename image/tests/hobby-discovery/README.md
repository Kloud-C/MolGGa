# 취미 찾기 결과 만화

다섯 결과 이미지는 각각 정사각형 2×2 네 컷 카툰입니다. 한 이미지 안에서는 주인공의 모습과 옷차림을 유지하고, 네 장면을 순서대로 보았을 때 취미를 시작해 작은 결과를 얻는 흐름이 대사 없이 이해되어야 합니다. 이미지 안의 글자, 말풍선, 캡션, 로고는 사용하지 않습니다. 새 그림으로 바꿀 때는 버전이 포함된 새 파일명을 쓰고 `assets/js/hobby-discovery-data.js`, 콘텐츠 탐색 카드 경로, 이 문서와 `image/README.md`를 함께 갱신합니다.

휴식 취향 결과 만화와 같은 인물이나 초록·크림 중심의 색감은 되풀이하지 않습니다. 다섯 유형은 서로 다른 인물, 공간, 색 팔레트와 그래픽 표현으로 구분하며 작은 썸네일에서도 행동을 알아볼 수 있게 단순하게 그립니다.

| 파일 | 결과 | 장면 |
| --- | --- | --- |
| `maker-v20261003-1.jpg` | 작은 것을 완성하는 메이커 | 짧은 보라색 머리 여성이 골판지를 접어 책상 정리함을 만들고 펜을 넣습니다. |
| `grower-v20261003-1.jpg` | 천천히 기르는 가드너 | 여성이 작은 컵에 씨앗을 심고 싹이 자라는 모습을 지켜봅니다. |
| `flavor-v20261003-1.jpg` | 새 조합을 찾는 맛 연구가 | 남성이 베리를 요구르트에 섞어 맛보며 간식 조합을 시험합니다. |
| `observer-v20261003-1.jpg` | 작은 차이를 기록하는 관찰자 | 남성이 구름 모양의 변화를 알아채고 스케치북에 기록합니다. |
| `puzzler-v20261003-1.jpg` | 규칙을 설계하는 퍼즐 메이커 | 여성이 도형 배열 퍼즐을 만들고 친구가 규칙을 찾아 완성합니다. |

새 이미지는 이전 결과 그림의 묘한 손·팔다리와 복잡한 구도를 개선하도록 가벼운 2D 카툰, 단순한 배경, 읽기 쉬운 동작으로 다시 생성했습니다. 게시 전 다섯 그림을 확대해 인물의 손·팔 개수와 연결, 네 컷의 흐름, 결과 문구와 첫 시도 예시의 일치를 확인했습니다. 이미지 대체 텍스트와 결과 설명은 `assets/js/hobby-discovery-data.js`와 네 언어 JSON 파일에서 관리합니다.
