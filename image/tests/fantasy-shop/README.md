# 판타지 마을 가게 이야기 이미지

모든 이미지는 따뜻하고 차분한 색감의 2D 판타지 게임 배경 일러스트입니다. 그림 안에 글자나 로고를 넣지 않았으며, 모바일에서 쓰기 좋도록 1600×900 WebP로 최적화했습니다. 장면 5와 8의 여행자는 짙은 녹색 망토와 갈색 배낭으로 같은 인물로 표현했습니다.

장면 이미지는 `assets/js/fantasy-shop-data.js`에 지정된 대체 텍스트를 함께 사용합니다. 장면이나 결과에 연결되는 파일명을 바꿀 때는 데이터 파일의 경로도 함께 수정해 주세요.

## 시작 및 이야기 장면

- `start.webp` — 숲과 성 사이의 마을 광장, 빈 점포, 게시판과 멈춰 선 마차
- `scene-01-location.webp` — 마을 입구, 광장, 책방 골목, 숲 근처가 함께 보이는 전경
- `scene-02-left-behind.webp` — 식탁과 의자, 선반, 작업대, 창가 화분이 있는 빈 점포
- `scene-03-market.webp` — 식재료, 여행용품, 수리 도구, 약초 씨앗과 유리병이 놓인 시장
- `scene-04-small-magic.webp` — 작은 생활 마법 도구를 보여주는 마을 마법사
- `scene-05-first-visitor.webp` — 비 오는 날 점포 문 앞에 선 첫 방문객
- `scene-06-sign.webp` — 빈 안내문과 펜, 이웃 상인이 있는 계산대
- `scene-07-closing.webp` — 해 질 무렵 닫힌 점포와 계산대 위의 장부
- `scene-08-returning-visitor.webp` — 맑은 날 다시 찾아온 같은 여행자

## 가게 결과

- `inn.webp` — 열린 문 너머로 식탁과 따뜻한 조명이 보이는 작은 여관
- `general-store.webp` — 밧줄, 양초, 물통과 작은 서랍이 갖춰진 잡화점
- `repair-workshop.webp` — 도구와 수리를 기다리는 생활용품이 있는 공방
- `herb-shop.webp` — 작은 정원과 약초 병, 잎을 말리는 채반이 있는 상점
- `magic-tool-shop.webp` — 빛나는 돌, 렌즈와 펜을 시험해 보는 마법 도구점
- `tea-shop.webp` — 창가 자리와 찻잔, 비스킷, 펼쳐진 책이 있는 찻집
