# 친구 여행 역할 테스트 결과 이미지

모든 이미지는 이미지 생성 도구로 만든 실사풍 장면입니다. `assets/js/travel-role-data.js`의 프로필 ID와 파일명을 맞춰 관리합니다.

- `planner.png` — 친구들이 듣는 가운데 숙소에서 일정표와 지도를 정리하는 여행 총무
- `navigator.png` — 역 안내 지도를 살피며 친구들에게 이동 방향을 알려주는 길잡이
- `food-scout.png` — 현지 시장에서 친구들과 먹을 음식을 고르는 맛집 탐험 담당
- `photographer.png` — 바닷가 산책 중 친구들의 사진을 찍어 추억을 남기는 담당
- `mood-maker.png` — 산 전망대에서 친구들과 셀카를 찍으며 분위기를 살리는 담당
- `budget-keeper.png` — 숙소에서 영수증과 여행 경비를 친구들과 정리하는 정산 담당
- `caregiver.png` — 산책로에서 지친 친구에게 물을 건네고 상태를 살피는 케어 담당
- `free-spirit.png` — 계획에 없던 바닷가 길을 발견하고 친구들을 이끄는 즉흥 코스 개척자

각 이미지에는 해당 결과의 역할이 장면에서 바로 드러나도록 인물과 행동을 넣었습니다. 이미지 교체 시 프로필과의 주제 일치, 인물 수, 손의 자연스러움, 파일 경로를 확인해 주세요.
