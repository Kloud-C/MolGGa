# 심야 기차 이야기 이미지

모든 파일은 1600×900 WebP입니다. 시작 장면과 선택 장면은 흑백 연필·잉크 스케치로, 결과 장면은 역별 분위기에 맞춘 절제된 컬러 동화풍으로 구성했습니다. 그림 안에 읽을 수 있는 문구나 로고를 넣지 않았습니다.

경로와 이미지 대체 텍스트 키는 `assets/js/night-train-data.js`에서 관리합니다.

## 시작 및 선택 장면

- `start.webp` — 불이 꺼진 승강장에 멈춘 낡은 밤기차와 열린 문
- `scene-01.webp` — 객실 안의 빈자리, 노선도, 여행 가방을 든 승객
- `scene-02.webp` — 창밖의 항구, 숲, 마을, 눈 덮인 지붕과 불빛
- `scene-03.webp` — 맞은편 승객이 펼쳐 보이는 글자 없는 그림엽서
- `scene-04.webp` — 수프와 차, 간식, 탄산수가 놓인 식당칸
- `scene-05.webp` — 이름 없는 승강장과 대합실, 지도, 매대, 화분
- `scene-06.webp` — 기차 창밖으로 보이는 역과 길, 가게, 오래된 건물
- `scene-07.webp` — 좌석 위 열린 가방과 목도리, 손전등, 동전, 수첩
- `scene-08.webp` — 창밖 어둠에 어렴풋이 비치는 네 도착역의 단서

## 도착역 결과

- `result-harbor.webp` — 등대가 보이는 밤바다와 작은 항구 식당
- `result-forest.webp` — 등불이 이어지는 숲길 끝의 산장
- `result-market.webp` — 늦은 시간까지 이어지는 음식 가판대와 시장 골목
- `result-snow.webp` — 눈 쌓인 플랫폼과 불 켜진 여관·빵집
- `result-greenhouse.webp` — 밤꽃이 핀 유리온실과 따뜻한 대합실
- `result-clock.webp` — 큰 시계와 오래된 승차권이 남은 벽돌 역
